# Lakshmi Sridhar — Portfolio & Art Commerce

Premium PHP website for original paintings, fine art prints, and painting courses.

## Stack

- PHP (modular includes + data files)
- Semantic HTML / custom CSS
- Vanilla JS
- GSAP + ScrollTrigger
- Font Awesome 6
- Google Fonts: Cormorant Garamond + Manrope

## Local preview

```bash
cd lakshmi-sridhar
php -S localhost:8080
```

Open http://localhost:8080

| Page | File |

## Before publishing

1. Replace placeholders in `includes/config.php` (WhatsApp number, Facebook URL, email, studio location).
2. Replace bracketed copy in pages / `data/*.php` with Lakshmi’s real details.
3. Swap SVG placeholders in `assets/images/artwork/` for real photography and artwork.
4. Wire the contact form to your preferred mail/handler service.
